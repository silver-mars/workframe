A structured repository of professional artifacts — roles (with agency, safety, and justification fields), methods, workplans, and projects — authored in Markdown with YAML front matter.
Each artifact progresses through the ESEO cycle (Exploration → Shaping → Evidence → Operation) and is assigned a maturity level (M0–M4). Designed for systematic performance measurement, evidence-based decision-making, and continuous work improvement.

## How to read this repo
- Each folder = one role context
- `methods/` = what I actually do (standard + extended)
- `works/` = evidence of application
